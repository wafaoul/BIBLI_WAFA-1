# BIBLI_WAFA

Application de gestion de bibliothèque 📚  
Projet développé avec **React** (Front) et **Node.js/Express** (Back).

## Fonctionnalités prévues
- Gestion des utilisateurs (Admin, Formateur, Étudiant)
- Catalogue de livres
- Panier et emprunts
- Authentification avec JWT

## Installation
```bash
git clone https://github.com/wafaoul/BIBLI_WAFA.git
cd BIBLI_WAFA
npm install
npm start
